**Group 69**

## Team

## Project Overview
An STM32-based simulation of an autonomous drone onboard computer, implementing sensor monitoring, mode switching, laser charging, attack detection and rescue behaviour.

## Hardware
- B-L4S5I-IOT01A Discovery Kit
- STM32L4S5VIT6 microcontroller
- Additional hardware enhancements documented separately

## Software
- STM32CubeIDE
- STM32 HAL and BSP
- Tera Term (UART monitoring)

## Core States
1. STANDBY
2. BATTLE
3. ATTACKED (The Last of EE2028)
4. TERMINATED
